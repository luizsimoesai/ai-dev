## RAG From Scratch

Pipeline de RAG montado à mão, sem framework, juntando as peças dos outros tópicos deste repositório.

- `fundamentals/document-parsing` → extração e chunking
- `fundamentals/embeddings` → geração de embeddings
- `fundamentals/vector-database` → armazenamento e busca
- `techniques/prompt-engineering` → construção do prompt final com o contexto recuperado

Versões com framework (LangChain) ficam em outros projetos: `agentic-rag`, `langchain-nextjs-fastapi-template`.
