## RAG From Scratch

Pipeline de RAG montado à mão, sem framework, juntando as peças dos outros tópicos deste repositório.

- `document-parsing-fundamentals` → extração e chunking
- `embeddings-fundamentals` → geração de embeddings
- `vector-database` → armazenamento e busca
- `prompt-engineering-fundamentals` → construção do prompt final com o contexto recuperado

Versões com framework (LangChain) ficam em outros projetos: `agentic-rag`, `langchain-nextjs-fastapi-template`.
