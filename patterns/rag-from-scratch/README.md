## RAG From Scratch

Pipeline de RAG montado à mão, sem framework, juntando as peças dos outros tópicos deste repositório.

- `knowledge/document-parsing` → extração e chunking
- `knowledge/embeddings` → geração de embeddings
- `knowledge/vector-database` → armazenamento e busca
- `patterns/prompt-engineering` → construção do prompt final com o contexto recuperado

Versões com framework (LangChain) ficam em outros projetos: `agentic-rag`, `langchain-nextjs-fastapi-template`.
